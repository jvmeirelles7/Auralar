## 📌 Sobre o Projeto
O **Veloce** é um projeto de loja virtual criado para treinar e aprimorar conceitos avançados de desenvolvimento front-end. O objetivo é construir uma interface fluida, responsiva e rica em componentes interativos (como gavetas laterais independentes, carrosséis de produtos e cálculos dinâmicos de carrinho), sem depender de frameworks pesados.

---

## ✨ Funcionalidades Implementadas
- 🛒 **Sacola / Carrinho Dinâmico:** 
  - Cálculo automático de subtotais e totais.
  - Barra de progresso interativa para **Frete Grátis** (a partir de R$ 1.500,00).
  - Sistema de Giftback automático (2%).
- ❤️ **Gaveta de Favoritos (Lista de Desejos):** 
  - Drawer lateral independente estruturada sem conflitos de classes com o carrinho.
  - Contador dinâmico de itens na barra de navegação (`badge`).
- 🎠 **Carrossel Reutilizável de Produtos:** 
  - Sistema de pílulas de categorias com filtragem em tempo real e setas de navegação independentes por seção.
- 🔍 **Modal de Busca e Navegação Responsiva:**
  - Atalhos de fecho por tecla `ESC` e overlay translúcido.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3** (Flexbox, Grid, variáveis e animações customizadas)
- **JavaScript (Vanilla / ES6+)** (Manipulação de DOM, eventos e lógica de componentes)
